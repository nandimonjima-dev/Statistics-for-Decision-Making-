# Statistics-for-Decision-Making
This project analyzes the Melbourne housing dataset to apply statistical decision-making techniques on real property data. It covers hypothesis testing, probability distributions, and ANOVA across 10 structured questions. Tests like One-Sample t-Test, Welch's t-Test, and Two-Way ANOVA were used to evaluate price differences across suburbs, seasons, and property features. Binomial and Empirical Probability were applied to estimate likelihood of specific property characteristics in Abbotsford. Key findings include a $875K bathroom premium, significant seasonal price variation, and strong suburb + property type effects on pricing.
